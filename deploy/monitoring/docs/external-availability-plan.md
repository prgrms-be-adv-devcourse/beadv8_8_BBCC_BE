# 외부 가용성 수동 진단·운영시간 유지

사용자는 운영시간 변경을 보류하기로 결정했습니다. 현재 AWS 자동 시작·정지 정책과 EC2 운영시간은 유지합니다. 명시적인 후속 결정 없이 24시간 운영으로 전환하지 않습니다.

이 PR은 수동 외부 진단 범위입니다. 정기 호출·상시 외부 감시·Slack 자동 통보는 활성화하지 않으며 #775 전체 완료를 뜻하지 않습니다. 앱 서버와 모니터링 서버가 함께 꺼지면 내부 Grafana는 알릴 수 없습니다.

| 확인 대상 | 현재 경로의 의미 |
| --- | --- |
| `https://dev-api.kidly.kro.kr/actuator/health` | nginx가 dev 앱에 직접 연결; Gateway 정상 증거는 아님 |
| `https://api.kidly.kro.kr/actuator/health` | nginx가 prod 앱에 직접 연결; 미기동이면 실패 가능 |
| 공개 대표 GET API | Gateway와 해당 서비스까지 확인. 대표 경로·응답 조건은 담당자 확인 후 고정 |
| `https://grafana.kidly.kro.kr/api/health` | 외부 nginx→medium Grafana 경로. Prometheus·Loki 전체 정상 증거는 아님 |
| TLS | 인증서 검증 성공과 만료 잔여일. 검증 우회 금지 |

## 제안

- 기존 GitHub Actions의 별도 수동 진단으로 시작합니다. 응답 본문·인증정보를 보관하지 않고 상태 코드·시간·TLS 결과만 기록합니다.
- 정기 호출은 운영시간과 prod의 실제 운영 시작을 확정한 뒤 활성화합니다. 의도적 dev 중지를 공개 장애로 중복 호출하지 않습니다.
- Actions 예약 실행은 지연·중단될 수 있고 GitHub 장애와 같은 실패 영역을 공유합니다. 24시간 오픈의 단독 장애 감지 수단으로 충분하다고 보장하지 않습니다.
- 전용 외부 감시 후보는 지역·연속 실패 횟수·복구 통보·TLS 만료 감지·비용·보관 정책을 비교해 승인 후 도입합니다. 새 외부 서비스는 아직 연결하지 않았습니다.

## 결정이 필요한 것

1. prod와 medium을 24시간 실행할지, 기존 9~18시 자동 시작/정지 정책을 유지할지 결정합니다. 24시간 전환은 EC2 비용에 영향을 줍니다.
2. 외부 감시 운영 주체, 확인 주기(후보 1~5분), 연속 실패 횟수(후보 3회), 알림 담당을 정합니다.
3. 실제 스케줄이 EventBridge·Lambda·외부 운영 도구 중 어디에 있는지 관리자와 확인합니다. Git 저장소만으로 AWS 계정의 예약 상태를 확정하지 않습니다.
4. 정기 실행과 Slack 전송 권한을 승인한 뒤 연결합니다. 테스트 목적으로 prod나 medium을 중단하지 않습니다.

## 완료 확인

- DNS·인증서·안전한 대표 GET의 정상 결과를 기록합니다.
- dev 경로를 시험 대상 URL에서만 통제해 연속 실패·해결 전송을 확인합니다. 실제 사용자 경로는 끊지 않습니다.
- medium 전체 중단 감지를 별도 실패 영역에서 검증합니다. prod 중단 시험은 별도 승인 대상입니다.
- 외부 감시와 운영시간이 미확정이면 오픈 점검표에 미완료로 남깁니다.

## 수동 진단 구현

`external-observation`은 수동 실행만 가능하며 정기 호출·Slack 통보를 활성화하지 않습니다.
앱 health(직접 경로), 대표 상품 GET(Gateway 경로), Grafana health와 TLS 잔여일을 조회합니다. 응답 본문·헤더·인증정보는 출력하지 않습니다.
대표 GET의 HTTP 성공은 조회 경로 접근 가능성만 뜻하며 업무 데이터의 정확성·완전성까지 검증하지 않습니다.
로컬 실행: `python3 deploy/monitoring/external_probe.py --environment dev`.

2026-11-04 외부 수동 조회에서 dev 앱 health·Gateway를 거친 대표 상품 GET·Grafana health 모두 HTTP 200을 확인했습니다. 관측 시간은 각각 약 135ms·1,237ms·88ms, TLS 잔여일 74일입니다.
이는 한 번의 읽기 관측이며 24시간 가용성·부하 성능·외부 알림 완료를 증명하지 않습니다. 응답 본문을 기록하지 않았습니다.
