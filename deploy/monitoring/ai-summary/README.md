# AI 운영 요약

Grafana → Kidly → **Kidly AI 운영 요약**. 서비스 오류 화면 위쪽 링크에서도 엽니다.
**30분 지표를 설명하는 참고 메모**이며 기존 경보·장애 대응을 대신하지 않습니다.

## 현재 상태

- 구현 승인됨. **유료 호출·키 등록·timer 활성화·공유 배포 검증은 아직 보류**
- 일반 모니터링 배포는 실행 전 안내 화면만 만듭니다. API를 호출하거나 timer를 설치하지 않습니다
- 기존 앱 코드·MCP Viewer 권한·AWS 운영시간을 바꾸지 않습니다

## 동작

예약 실행 → localhost Prometheus 고정 쿼리 → 허용한 환경·서비스명과 숫자만 추출 → OpenAI Responses API → 별도 dashboard 파일 생성.
Grafana는 읽기 전용 볼륨에서 읽습니다. 게시 토큰·새 플러그인·새 이미지·상시 웹 서버는 없습니다.

- 운영 대상/환경 중지/전환/수집 신선도는 코드로 판별합니다. AI가 정상 판정으로 바꾸지 않습니다
- 요청 건수·오류 건수·응답시간 합은 최근 30분 추정치. 자원·풀·lag는 현재 관측값입니다
- 없는 지표·분모 0·저트래픽은 정상 증거가 아닙니다. 서버 자원은 전체 서버 중 최악 값이며 원인 서버를 단정하지 않습니다
- 응답은 최대 3개 항목, 근거 ID를 검증하고 HTML을 이스케이프합니다. 로그·원본 라벨·식별값은 전송하지 않습니다
- 실패 시 마지막 성공 결과와 시각을 보존하고 최근 실패를 표시합니다. 상단 경과 시간이 1시간을 넘으면 빨간색입니다
- 수집이 끊기면 상단 상태는 미수집으로 표시합니다. 본문 시각·참고 기한을 반드시 확인합니다

## 활성화 전

모델·비용·호출 상한 승인 → 안전한 키 주입 → dev 1회 실행·실패/원복 확인 → timer 활성화 순서입니다.
현재 전용 계정/API 키를 만들지 않았습니다. 키를 채팅·PR·명령 인자에 넣지 마세요.

운영자는 승인 뒤 `/etc/kidly-ai-summary/settings`를 `settings.example` 기준으로 만듭니다.
키 파일은 별도로 deploy만 읽도록 보관하고, 위 설정 파일에는 경로만 둡니다.
`OPENAI_LIVE_ENABLED=1`, 승인 모델, 하루 상한(1~48), 키 파일이 모두 있어야 호출합니다.
서비스/timer 파일을 systemd에 설치한 뒤 승인된 1회 검증을 먼저 수행합니다. 일반 deploy는 이를 수행하지 않습니다.

- 실행 상태: `/opt/app/monitoring/ai-summary-state/state.json` (0600, 마지막 성공 1개와 호출 예약 건수만 유지)
- dashboard: 같은 경로의 `dashboards/` (Grafana 읽기 전용). 기존 버전 관리 dashboard는 덮어쓰지 않습니다
- 상태 지표: `operations/ai-summary.prom`을 기존 Alloy가 수집합니다. 요약 문장은 라벨에 넣지 않습니다
- 중복 실행은 잠금으로 차단합니다. 작업 종료 후 30분 간격, UTC 하루 상한, 실패도 호출로 계산하며 자동 재시도하지 않습니다
- API 입력 전체 JSON 최대 24KB, 출력 최대 1,200토큰, HTTP 20초, 작업 300초, 메모리 96MiB 상한입니다
- 중지: timer를 disable/stop하고 실행 중인 service도 stop. 키 폐기 후 LIVE_ENABLED=0. 상태/호출 장부는 지우지 않습니다
- 장부 삭제·동시 별도 인스턴스·다른 API 사용은 상한 밖입니다. 상한은 달러 예산의 강제 제한이 아닙니다

## 로컬 검증

`python3 -m unittest discover -s deploy/monitoring/tests -p 'test_*.py'`

`summary.py --state-dir /tmp/kidly-ai-preview --fixture <합성 지표 JSON>`으로 네트워크 없이 미리보기를 만듭니다.
`--state-dir <경로>`만 실행하면 기존 성공 결과를 유지하며 초기 화면을 만듭니다.

상태 장부 손상 시 배포를 실패시켜 원인을 드러냅니다. 상태를 지워 우회하지 말고 복구하세요. 비정상 종료는 다음 실행/배포에서 표시합니다.
