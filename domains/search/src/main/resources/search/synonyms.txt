# 검색 동의어 사전 (#1025). 검색할 때만 쓰므로 고치면 검색 서비스를 다시 띄우는 것만으로 반영된다(색인을 다시 채우지 않는다)
# 형식: "가, 나, 다" = 양방향(어느 말로 찾아도 모두) · "가 => 나, 다" = 한 방향(가로 찾으면 나 · 다도)
# 찾는 말(양방향은 모든 말, 한 방향은 왼쪽)은 공백 없는 한 단어. 넓힌 말은 여러 단어여도 된다
# 뜻이 넓은 말(세트 · 상의 등)을 양방향으로 묶으면 엉뚱한 상품까지 나오므로 한 방향으로 둔다
# 고친 뒤에는 평가 세트(apps/search-service 테스트 resources의 search-quality)로 결과가 나빠지지 않는지 본다
